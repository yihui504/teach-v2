# EXAM-BLUEPRINT-FORMAT — 考点蓝图格式

`EXAM-BLUEPRINT.md` 是工作区的考试地图。它只记录**有出处**的考点；推断必须标 `待验证`。

## 必含章节

1. **材料与置信度**：每份材料的状态（未解析 / L1 / L2 / L3）、置信度、备注。
2. **卷面结构（按套）**：每套卷一张表，题型 × 题量 × 分值 × 小计。
   - **不要合并成一套**；不同年份差异可能很大。
3. **考点矩阵**：见下。
4. **命题方式**：题型 → 常见问法 → 来源。
5. **待办**：未解析材料、待验证行。

## 考点矩阵字段

| 字段 | 说明 |
|---|---|
| ID | 领域前缀 + 序号，如 `DEAD-04`、`MEM-06` |
| 考点 | 一句话，可被命题 |
| PPT 锚点 | 文件名 + 页码范围 |
| 教材锚点 | 书名缩写 + 章节 |
| 已见题型 | 单选 / 判断 / 填空 / 简答 / 问答 / 计算 / 程序 / 应用设计 |
| 已见分值 | 写区间，如 `16–20`；没见到写 `—` |
| 状态 | `未教` / `已教` / `已练` / `已掌握` / `待验证` |
| 教学课 | 课次，如 `0029`；没排课写 `00xx（计划）` |
| 练习专题 | `drills/<slug>`；没有写 `—` |

## 规则

- **来源优先**按 `CONFIG.md` 的 `source_priority`；默认范围听老师重点、题型听往年卷、正文听 PPT。
- **一套卷一列结构**，不取平均、不写死配比。
- **状态只升不降**，除发现错误；降级要写学习记录。
- **掌握只认产出型证据**：填空、计算、口头说理；选择题全对不算。
- 每新增一个考点，必须在 `COVERAGE.md` 有对应行。
- 任何 `待验证` 行不得进入 `drills/` 的必考内容。
