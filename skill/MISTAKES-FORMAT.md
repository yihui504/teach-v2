# MISTAKES-FORMAT — 错题本格式

`MISTAKES.md` 只记**有诊断价值**的错，不记流水账。
它的用途不是"再看一遍答案"，而是**找出错误的类型**。

## 错因四分类

| 类型 | 判据 | 对策 |
|---|---|---|
| `概念混淆` | 把 A 当成 B，或定义边界不清 | 回炉重讲，补对比表 |
| `算错` | 思路对，数字/步骤错 | 加计算步骤模板，限时重算 |
| `审题` | 看漏条件、答非所问 | 练"先划条件再动笔" |
| `蒙对` | 答对但说不出理由 | 按错题处理，进复习队列 |

## 表结构

| 题 ID | 概念 | 错因 | 正确思路 | 复发次数 | 最近复发 |
|---|---|---|---|---:|---|

- **正确思路**写判断依据，不写答案复述。例：
  - ✅「先看 Request ≤ Need，再看 ≤ Available，最后试分配」
  - ❌「答案是 A」
- **复发次数**每次在复习队列中再错就 +1。
- 同一概念复发 ≥2 次 → 在 `learning-records/` 写一条，并在小结课重讲。

## 不要写进来的东西

- **范围判断**（如「这个点 PPT 没讲，不考」）不是错题，写到 `NOTES.md` 的「加餐」行或蓝图 `待验证`。
- 没有真实作答记录的题（`Q?` 这种 ID）不要编。
- 只写「答案是 X」而不写判断依据的，退回去重写。

## 与其它文件的关系

- 题 ID 与 `REVIEW-QUEUE.md` 一致。
- 错因里出现 `概念混淆` 的，检查 `GLOSSARY.md` 是否有该术语；没有就补。
- 错因里出现 `审题` 的，检查题目是否题干过长或条件藏得太深。
