# REVIEW-QUEUE-FORMAT — 复习队列格式

`REVIEW-QUEUE.md` 记录**什么时候该重测什么**。它是间隔复习唯一的落地载体。

## 规则

1. 每题有稳定 ID：`<课次>-Q<题号>` 或 `drills-<slug>-Q<题号>`。**必须带 `-Q<题号>`**，只写 `drills-banker` 不算。
2. 答错、蒙对、口头不过 → 入队，`复习次数 = 0`。
3. 连续两次答对 → 出队，移到「已完成」保留 30 天。
4. 节奏读 `CONFIG.md`：
   - `every_5_lessons`：`下次复习 = 当前课次 + 5`
   - `time_based`：按 1/3/7/14 天
5. 周期小结课只做队列里的题，不引入新内容。
6. 队列里同一概念超过 3 题，合并成一次概念重讲。

## 表结构

### 待复习

| 题 ID | 概念 | 考点 ID | 来源 | 首次答错 | 下次复习 | 复习次数 | 状态 |
|---|---|---|---|---|---|---|---:|---|

- 状态：`待首次复习` / `已复习` / `卡住`（连续两次仍错，触发重讲）。

### 已完成

| 题 ID | 概念 | 连续答对次数 | 出队日期 |
|---|---|---:|---|

## 小结课的产出

- 不新建课程文件；在 `lessons/` 下建 `NNNN-review-<范围>.html`，只含错题重测与概念重讲。
- 结束更新 `MISTAKES.md` 的复发次数。
- 若某概念连续两次仍错，在 `learning-records/` 写一条记录，说明卡在哪。
