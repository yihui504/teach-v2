# EXAM-FORMAT — 整卷模拟格式

`exams/mock-NN.html`，两位数递增。一卷一次限时作答。
**范围只覆盖已教考点**（考教一致）；未教章节不出题，并在卷面说明里写明。

## 卷面结构

- 按 `EXAM-BLUEPRINT.md` 里**每一套卷自己的结构**缩比组卷；当前学期以老师划重点为准。
- 卷首必须有「卷面说明」块：原卷结构 vs 本卷缩比对照表、总分、限时。
- 缩比建议：半程卷取题量 1/2、大题取 1 题；同步编程可简化但保留四步法全流程。

## 块结构（`check_lesson.py --kind drill` 验收）

| 块 | 本卷中的形态 |
|---|---|
| `block-exam` | 卷面说明：结构对照表 + 考场规则 |
| `block-derive` | 各题型考场作法（公式、四步法、甘特图画法速引） |
| `block-produce` | 全部大题（简答/计算/编程），`data-answer="hidden"`，每题 `<details>` 藏答案 + **逐项评分点** |
| `block-trap` | 考场易错（绝对词判断题、公式串用、时间分配） |
| `block-remember` | 考试策略三句话 |
| `block-source` | 卷面结构出处、原题出处、≥3 个可点击链接；变式题标 `AI 推导` |

- 单选题走 `quiz.js`，题 ID `exams-mock-NN-Qx`，选项等长 + 位置分散（闸门卡方检验）。
- 判断/填空为静态题干 + `<details>` 答案（不进 renderQuiz，闸门只统计选择题）。

## 作答闭环

1. 交付时给 `file:///` 路径 + 限时说明；学员限时作答。
2. 单选点「复制结果」发回 JSON；大题拍照/打字发回。
3. agent 判大题（按评分点）、错题按 MISTAKES 四分类归因。
4. 更新 `COVERAGE.md` 的「模拟考记录」表（卷次/日期/得分/用时/归因/补强动作）。
5. 下一卷范围按本次错因定；错题全部进 REVIEW-QUEUE。

## 与其它线的关系

- mock 不讲新概念；讲概念是 `lessons/` 的事，刷单考点是 `drills/` 的事。
- 冲刺期（考前 ≤7 天）优先排 mock，新课只排框架卡（正文可低于 4,000 字符，WARN 在 COVERAGE 记录从简理由）。
